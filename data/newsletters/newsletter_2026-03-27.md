### [Shadow DOM Focus Delegation: Getting delegatesFocus Right](https://frontendmasters.com/blog/shadow-dom-focus-delegation-getting-delegatesfocus-right/)
*Frontend Masters · Rob Levin*

This post explains how to use the `delegatesFocus` feature in Shadow DOM to simplify focus management for web components. It details three key benefits: automatic focus delegation to internal elements on host clicks, consistent `:focus` styling via CSS, and preventing 'stranded focus' for accessibility. The article includes practical examples using LitElement, guidelines for when to enable `delegatesFocus` (simple wrappers like buttons/inputs) versus when to avoid it (complex components with custom focus logic), and implementation tips for AgnosticUI components. It also highlights common pitfalls like avoiding `tabindex` on the host element.

[Read more](https://frontendmasters.com/blog/shadow-dom-focus-delegation-getting-delegatesfocus-right/)

### [The Site-Search Paradox: Why The Big Box Always Wins](https://smashingmagazine.com/2026/03/site-search-paradox-why-big-box-always-wins/)
*Smashing Magazine · hello@smashingmagazine.com (Carrie Webster)*

This article explores the 'Site-Search Paradox,' where users often prefer Google over internal site search due to poor implementation of information architecture (IA) and user-centric design. It highlights how traditional site search relies on exact string matches rather than semantic understanding, leading to high exit rates and lost conversions. The author provides a four-phase audit framework and practical UX strategies to improve search by addressing synonym gaps, fuzzy matching, and intent-based filtering. Case studies demonstrate the impact of aligning metadata with user language, emphasizing that better IA—not just technical fixes—is key to solving search issues. The piece concludes with a checklist for creating a search experience that guides users toward their goals without penalizing natural language use or typos.

[Read more](https://smashingmagazine.com/2026/03/site-search-paradox-why-big-box-always-wins/)
